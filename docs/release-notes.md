**本次软件更新前建议先对已部署帧生成的游戏还原**
【更新】
1.帧生成资产升级到 0.4.1：内核/后端/xefg/超分文件全部更新，代理与 INI 同步；Optimized 出厂档位改为 1（与官方逐位一致）
2.DLSS-G 预设改为 A / B / C（Auto 已删除，默认 A）

1.SM部署不再因 VC++ 运行库版本被拦截。

3.部署/启动提速：不再备份自有资产、大文件快速校验、效果包增量铺、旧版扫描与图标延后
